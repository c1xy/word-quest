# ⚔️ 单词大冒险 · 背单词小游戏

把背单词做成打怪闯关 RPG：**打怪、闯关、记单词**。纯前端单机网页，无需安装、无需联网、无任何依赖。

## 🚀 怎么玩

在线版（手机可安装离线玩）：**https://c1xy.github.io/word-quest/**

本地版：直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。

**📱 安装到手机/桌面（PWA 离线可玩）**：用本地服务打开（在 word-quest 目录运行 `python -m http.server 8931` 或 `npx serve`，手机访问 `http://电脑IP:8931`），然后浏览器菜单选「安装应用 / 添加到主屏幕」。之后无需联网也能玩，更新文件后自动生效。

> 进度自动保存在浏览器 localStorage 里，关掉页面也不会丢。换电脑可用设置页的「导出/导入存档」。

## 🎮 游戏模式

主页菜单按玩家旅程分四组：**⚔️ 主线冒险**（冒险模式 / 词魂肉鸽）、**📅 每日仪式**（每日远征 / 词根合成实验室 / 听写挑战）、**🤝 与人同乐**（投毒挑战码 / 双人热座对决）、**🛠️ 创作工坊**（词境工坊 / 主题挑战包）；无尽挑战、复习模式、记忆配对收在分组下方一行。首次启动主页顶部有一条「从这里开始 → 主线冒险」引导条，完成首次冒险通关后自动永久隐藏。错题本 / 单词图鉴 / 成就 / 天赋 / 设置 / 玩法说明 / 反馈等工具仍在底部工具行。

## 📲 接力码（跨设备搬档，零服务器）

设置页「📲 接力码」：全量存档 DEFLATE 压缩 + base64 后编码成一张或多张二维码——PC 展示、手机扫码即打开同一网址（`#r=i/n` 分片协议）自动恢复全部进度；反方向同样成立，也可以复制完整文本粘贴恢复。存档超过单码实用容量（实测标定约 900 字符/码）自动分片，恢复端按序集齐、整包 CRC 校验后合并。恢复前弹确认框并**自动把接收设备现有存档导出为一次性备份接力码**防误覆盖；接力语义=**复制不是移动**，两台设备各自独立继续。生成时可勾选「连同进行中的对局一起接力」——关卡号/本局词表/城防/金币/连击随码迁移（冒险/无尽/词魂/主题包支持；毒池局与远征局只接力存档）：恢复确认框里「同时续接接力码里进行中的对局」保持勾选（默认）即恢复后自动续接，取消勾选则只恢复存档。

## 🌌 词境工坊（玩家自制关卡 UGC）

主界面「🌌 词境工坊」三步造一个专属词境：① **选词源**——从 4 个主题挑战包与错题本勾选（同组勾选确定性抽样同一份词表），或粘贴自定义词表（必须在内置 2909 词词典内，上限 30 词）；② **选词缀**——14 条 BOSS 词缀池最多挂 2 条，整局生效；③ **调参数**——城防血量（×0.5~2.0）/怪物血量（×0.5~3.0）/每题时限（×0.5~2.0），可写 ≤50 字开场引言进词境时横幅展示。「📤 生成词境码」复用接力码的分片+CRC 管线（`RM.` 文本前缀 / `#m=i/n` 扫码协议，30 词+参数+引言单码可承载、超长自动分片）；「💾 保存到我的词境」本地列表（存/重玩/分享/删除，坏档自动清理）。好友粘贴词境码 → 摘要确认（词数/词缀/引言/参数）→ 开战：走显式词池 + 词缀注入，词境战斗照常写回掌握度与间隔重复。

## 🎤 口语跟读（说出来才算学会）

听写挑战出战页的「🎤 跟读」开关（记忆在存档）：开启后每题先出词面并示范发音，按住麦克风读出单词——浏览器语音识别（Web Speech Recognition，en-US）与目标词比对，**整词命中或编辑距离相似度 ≥80% 判过**（大小写/标点/赘词容错），判过直接进入 SRS 记忆流程；判不过给出识别内容与正确发音，可重说或改用拼写。跟读成绩进结算（🎤 跟读 N/通过 M）。需要浏览器内置语音识别能力并联网（Chrome/Edge 支持较好，Firefox/Safari 部分不支持）；不支持的浏览器自动隐藏开关，识别连续 3 次不可用/无权限本局自动关闭——答题流程完全不受影响。

## 🖼 分享卡（战绩出图）

毒池结算页、每日远征结算页、词魂肉鸽结算页均有「🖼 分享卡」按钮，投毒战绩弹窗每条战绩右侧也有 🖼 小按钮：离屏 canvas 合成 900×1200 竖版战报（大字标题 + 关键数据 + 日期 + 二维码 + 游戏名角标，游戏同款配色）。手机支持直接拉起系统分享；电脑自动弹出预览并可下载 PNG。同一战绩多次点击复用同一画布，不重复生成。

## 📕 错题本（跨局累积）

答错的词自动入册；主页「错题本」查看全部错词（按答错次数排序），一键发起**强化训练**（只刷错题、不扣血）；某词答对升到 3 星即自动攻克出册。

## 🧩 高迷惑选择题

默认只出一种题型：**给出中文释义，从四个英文单词里选出答案**。干扰项按迷惑度挑选：**你混淆过的词 > 同词根词 > 同开头两字母 > 同首字母 > 同词性近长度**——比如考 industrial 时选项是 intelligent / independent / individual。其它题型（看英选中 / 听音选词 / 拼写）可在设置里开启。

## ✨ 游戏系统

- **📔 单元制学习**：四级/六级词库按 20 词一切单元（Unit 1~30 / Unit 1~22），出战设置选「自动跟随进度」，新词就严格按单元顺序推进（像背单词书），学完一个单元自动解锁下一个；复习仍按遗忘曲线全局调度
- **🧠 自适应间隔算法**：每个词有专属难度系数——一次答对间隔系数变大（最长 2.8 倍）、答错缩短（最短 1.2 倍）、重考后才答对不加长。越熟的词越少出现，越生的词越常回访
- **📖 单词详情卡**：图鉴里点任意单词——发音、释义、词汇密码、同根词家族、答题统计、下次复习时间一目了然；可手动「标记已掌握 / 重置记录」

- **📅 每日任务**：每天 0 点刷新 3 个随机任务（答对题数 / 拼写 / 击杀 / 复习…），完成领金币，和连续打卡一起形成每日学习习惯
- **🏆 成就墙**：31 个成就（连击、掌握词数、打卡天数、远征先锋、词根炼金师、词缀图鉴…），解锁即得金币奖励
- **🐣 宠物系统**：商店可购买 4 只宠物（🦉答题时间+15% / 🐉金币+15% / 🧚每关回血 / 🐢减伤），永久拥有、任选一只出战
- **👹 BOSS 词缀**：时间压缩 / 狂暴 / 荆棘 / 汲取 / 时停 / 贪婪 / 石肤 / 沉默 / 狂潮 / 不死 / 贫瘠 / 诅咒 / 迷雾 / 妖印共 **14 种**随机机制 + 濒死狂暴（残血提速），BOSS 战与每日远征精英关各不相同
- **⚡ 连击爆发**：每 5 连击触发全屏爆发，回血 + 额外金币
- **🎵 背景音乐**：默认关闭；想听可在设置里开启（8-bit 循环 BGM，BOSS 战自动切曲）
- **📜 关卡剧情**：迷雾森林 → 荒芜沙漠 → 极寒冰原 → 熔岩火山 → 魔王城堡，五大场景配剧情文案
- **📊 自适应难度**：连续答得好悄悄收紧答题时限，感觉吃力自动放宽（无感知调节）
- **🔍 记忆提示（词根 + 图像双通道）**：答题时点「记忆提示」，查看该词的 **emoji 图像联想 + 词根拆解 + 同根词家族**（如考「n. 农业」提示 🚜 `agri(田地) + culture(培养)`）——先想再看，记忆更深；内置 262 个词的图像映射，全部离线可用
- **🔑 词汇密码**：内置约 110 组词根词缀 + 双解析择优算法，答错时记忆卡片自动拆解单词（如 `im-(进入) + port(携带)`、`geo(地球) + graph(写/记录)`），并展示**同根词家族**（important / opportunity / support 都带着 port！）点击即发音
- **🎤 语音跟读**：记忆卡片上的跟读挑战——大声朗读单词，语音识别匹配成功 +5 金币（开口是最高效的记忆通道；浏览器不支持时自动隐藏）
- **⚔️ 混淆对决**：答错选择题会自动记录你搞混的词对，图鉴页「易混淆词对」可一键发起 2 词速决对决，赢一次清除档案
- **🧠 智能干扰项**：记住你混淆过的词，下次专门用它们当错误选项来考你
- **📈 学习仪表盘**：单词图鉴页 canvas 图表——12 周学习热力图 + 近 7 天答题柱状图 + 掌握度分布环形图
- **🎉 仪式感动效**：BOSS 击杀 / 通关 / 成就解锁全屏彩带，连击音调逐级升高，受击屏幕微震（系统开启「减少动态效果」时自动关闭所有动画）

## 🧠 它是怎么让你记住单词的

- **间隔重复**：每个词 0~5 星掌握度，答对升星、答错降星；低星词和到期词优先出现，满星词几乎不再出现
- **主动回忆**：四种题型混搭——看中文选英文 / 看英文选中文 / 字母拼单词 / 听发音选词（调用系统 TTS）
- **即时强化**：答错立刻弹「记忆卡片」（单词 + 释义 + 发音），关闭后**换题型马上重考**同一个词
- **复仇怪物**：答错两次的词会变成复仇怪物，隔几题再回来偷袭你
- **多感官**：拼字母、听发音、看释义，答题后自动朗读单词
- **连续打卡**：每天答题累计连续天数，中断清零

## ✏️ 自定义词库

主菜单 → 单词图鉴 → 我的词库，粘贴你自己的单词表（每行一个）：

```
apple n. 苹果
abandon v. 放弃
dictionary n. 词典
```

英文和释义之间用空格、冒号或制表符分隔均可，保存后在「出战准备」里勾选即可。

## ❓ 常见问题

- **听音题没声音 / 不可用**：听音题依赖系统英文语音包。Windows 可在「设置 → 时间和语言 → 语音」添加英文语音；没有英文语音时游戏会自动禁用该题型，其余功能不受影响。
- **想重置进度**：设置页 → 「重置全部进度」。
- **想改词库内容**：编辑 `words.js`，按 `['单词', '词性. 释义']` 格式添加即可。
